# 回忆相册照片

把照片直接放在这个文件夹里。相册会在网站下次构建、部署后自动显示，不需要逐张修改配置。

- 页面地址：`/zy-and-i/memories/`，入口在 ZY and I 页面的 LOVE TOOLS 区域。
- 支持 `.jpg`、`.jpeg`、`.png`、`.webp`、`.avif`、`.gif`，扩展名大小写均可。
- 按文件路径的字母顺序排列。建议用 `001-first-date.jpg`、`002-walk.jpg` 等名称，方便控制顺序；中文文件名也支持。
- 建议导出长边 1600–2400 像素的照片，尽量控制在每张 1–2 MB 内，手机打开更快。
- 原图查看保留完整画面；网格缩略图会居中裁剪。
- 删除照片文件并重新部署，就会从相册中移除。

## 可选：为照片添加说明和日期

编辑 `_data/zy-and-i-album.yml`，把 `photos: []` 改为：

```yaml
photos:
  - file: "001-first-date.jpg"
    caption: "第一次一起吃晚饭"
    date: "2026-08-19"
    alt: "我们坐在餐厅窗边"
  - file: "002-walk.jpg"
    caption: "晚饭后，慢慢走回家"
```

`file` 要与实际文件名完全一致（包括大小写）。若使用子文件夹，填写 `旅行/001.jpg` 这样的相对路径。没填说明的照片会显示“一起的时光”，日期可不填。

这个相册随 GitHub Pages 网站公开发布；`noindex` 仅用于告知搜索引擎不收录，并非访问密码或权限保护。
